# undangan-digital-Designing-a-luxury
Designing a luxury

Merancang undangan pernikahan mewah dalam satu file HTML.
Menyusun sistem warna, tipografi, dan tata letak halaman.
Merancang setiap bagian undangan mulai dari galeri hingga RSVP.
Menambahkan fitur buku tamu, hadiah digital, musik, dan navigasi.
Menentukan palet warna, jenis huruf, dan gaya tombol elegan.
Menyusun struktur HTML lengkap dan rencana fitur interaktif.
Menulis konten cerita cinta dan detail pasangan mempelai.
